# Model Roadmap

## Stage 0: Smoke Test

Goal: verify the local pipeline without public downloads.

Inputs:

- Synthetic CTG-like traces generated by `scripts/00_setup/generate_synthetic_ctg.py`.

Outputs:

- Synthetic long-format CTG file.
- Feature table.
- Baseline risk-score metrics.
- Project status report.

## Stage 1: Reproducible CTU-UHB Ingestion

Goal: ingest the primary raw signal cohort.

Steps:

1. Download CTU-UHB files from PhysioNet.
2. Parse WFDB headers and metadata.
3. Read FHR/UC signals.
4. Build a record-level cohort table.
5. Build a windowed signal table or tensor dataset.

Deliverable:

- `data/processed/ctu_uhb_record_index.csv`
- `data/processed/ctu_uhb_window_index.csv`
- `data/processed/ctu_uhb_record_features.csv`

## Stage 2: Clinical Feature Baselines

Goal: create strong conventional baselines before deep learning.

Feature groups:

1. FHR baseline, mean, median, SD, short-term variability proxy.
2. FHR acceleration and deceleration counts.
3. Time below or above clinically plausible thresholds.
4. UC frequency, intensity, and spacing.
5. FHR-UC lagged coupling.
6. Missingness and signal quality.

Models:

1. Logistic regression.
2. Random forest.
3. Gradient boosting.

## Stage 3: Self-Supervised Pretraining

Goal: learn reusable CTG representations.

Architecture candidates:

1. PatchTST-style transformer for multichannel time series.
2. Temporal convolutional encoder.
3. Small transformer encoder with masked reconstruction.

Pretraining tasks:

1. Masked segment reconstruction.
2. Contrastive same-record segment learning.
3. Future segment prediction.

## Stage 4: Dynamic Phenotyping

Goal: turn embeddings into clinically named fetal risk phenotypes.

Approach:

1. Cluster embeddings.
2. Describe clusters by conventional CTG features.
3. Visualize prototype traces and risk gradients.
4. Test associations with pH and Apgar outcomes.

## Stage 5: External Validation

Goal: avoid a single-dataset AI paper.

Validation options:

1. CTGDL harmonized CTU-UHB files: preprocessing reproducibility.
2. CTGDL non-CTU source files: external validation if license permits.
3. UCI feature dataset: conventional feature baseline comparability only.

## Stage 6: Manuscript-Grade Evidence

Minimum required outputs:

1. Transparent source manifest.
2. Cohort flow diagram.
3. Model comparison table.
4. Calibration and decision curve figures.
5. Phenotype prototype traces.
6. Subgroup performance table.
7. Model card and reproducibility checklist.
