# Official Frontiers LaTeX template package

This folder adapts the manuscript to the official Frontiers LaTeX template supplied by the user.

Main files:
- frontiers_ctg_manuscript.tex
- frontiers_ctg_manuscript.pdf
- frontiers_ctg_supplementary_material.tex
- frontiers_ctg_supplementary_material.pdf
- references.bib
- figures/*.jpg
- Frontiers class and bibliography style files copied from the official template zip

Formatting choices:
- Document class: FrontiersinHarvard
- Bibliography style: Frontiers-Harvard
- Target journal: Frontiers in Signal Processing
- Specialty: Biomedical Signal Processing
